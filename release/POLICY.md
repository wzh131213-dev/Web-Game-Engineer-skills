# Version, release and certification

Core, each Module and each Adapter have independent versions. Stable, Beta and Experimental are distinct. GitHub is official source; distribute a full ZIP and platform packages with guides, compatibility matrix, SHA-256 and SBOM.

Levels: L1 basic guidance; L2 instruction-led/manual execution; L3 main tools work with some manual steps; L4 full workflow tools. L1-L2 remain Experimental. L3-L4 may apply for certification but do not automatically pass.

Each platform independently passes actual installation, capability detection, benchmarks, project handoff, security, regression and delivery tests. Revalidate at least every 90 days and after major host/tool changes or severe defects. Suspend affected certification for confirmed severe security/data-integrity issues.

Build adapters concurrently where possible; isolate failures. Unfinished platforms may receive Experimental packages but must not be called formally compatible. User approval is required for public release, Stable replacement, remote push and deployment.
