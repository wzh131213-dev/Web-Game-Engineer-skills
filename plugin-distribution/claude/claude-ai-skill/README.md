# Claude.ai Skills package

This folder is the source for the Claude.ai Agent Skills ZIP. The archive contains a single skill directory with `SKILL.md` at its root, suitable for the Skills upload workflow where that feature is available.

Claude.ai Skills and Claude Code plugins are different installation targets. The Claude.ai archive does not contain the Claude Code `.claude-plugin/plugin.json` manifest; use the separate Claude Code plugin ZIP for Claude Code.

Status: Experimental / NOT CERTIFIED. The ZIP layout can be validated in CI; installation and runtime behavior still require testing in the target Claude account.
