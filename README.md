# Web & Game Engineer

**Release:** 0.1.2-alpha · **Channel:** Alpha · **Certification:** no platform certified

A cross-AI engineering Skill with one shared Core, nine professional modules, seven virtual roles and independently versioned platform adapters. Platforms are used separately; no AI-to-AI communication is required.

## Current work
The ChatGPT adapter now has a consolidated portable source package at [packages/chatgpt](packages/chatgpt). It provides conditional installation routes and capability-aware instructions. It does not assume native Skill or ZIP import support. The adapter remains Experimental / NOT CERTIFIED until installation and acceptance tests are evidenced.

## Start
1. Read `SKILL.md`.
2. Read `adapters/chatgpt/README.md` or the relevant platform adapter guide.
3. For the consolidated ChatGPT package, start at `packages/chatgpt/INSTALL.md`.
4. Follow only an installation path actually supported by the target account.
5. Run adapter acceptance tests and record evidence.

All platform certifications are independent. See `release/POLICY.md` and `release/acceptance-matrix.csv`.
