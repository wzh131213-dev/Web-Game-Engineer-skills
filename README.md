# Web & Game Engineer

**Release:** 0.1.1-alpha · **Channel:** Alpha · **Certification:** no platform certified

A cross-AI engineering Skill with one shared Core, nine professional modules, seven virtual roles and independently versioned platform adapters. Platforms are used separately; no AI-to-AI communication is required.

## Current work
The ChatGPT adapter has been expanded with conditional installation routes, host capability detection, a host instruction wrapper, test cases and a certification record. Its status remains **Experimental / NOT CERTIFIED** until target-host installation and all required tests are evidenced.

## Start
1. Read `SKILL.md`.
2. Read `adapters/chatgpt/README.md` for ChatGPT, or the relevant platform adapter guide.
3. Follow only the installation path actually supported by the target account/product.
4. Run the adapter acceptance tests and record evidence. Do not infer compatibility from the presence of files.

All platform certifications are independent. See `release/POLICY.md` and `release/acceptance-matrix.csv`.
