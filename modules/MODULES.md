# Nine professional modules / 九大专业模块

All modules are enabled at product level and loaded only when relevant. Each module converts a concise brief into concrete implementation and acceptance checks.

1. **Web Development:** HTML5/CSS/JS/TS, responsive information architecture, design tokens, forms, routing, state, storage, accessibility and performance. Deliver a navigable product with real primary interactions.
2. **2D Game Development:** game loop, coordinate/input model, characters, animation, collision, maps/levels, progression, pause/restart and saves. Deliver a complete playable vertical slice.
3. **3D Game Development:** Three.js, scene/camera/light/materials, terrain/geometry/models, collision, world boundaries and resource lifecycle; WebGPU optional. Deliver a coherent 3D scene with real controls.
4. **3D Workbench:** scene/object create/select/transform/inspect, material editing, asset management, undo/redo where appropriate and export.
5. **Physics Engine:** Physics Core, Vehicle, Character, Environment and Destruction Physics; define units, timestep, contacts and stability; Rapier may provide primitives.
6. **Animation System:** skeletons, keyframes, state machines, blending, IK and event-driven transitions.
7. **AI Game Logic:** NPC state machines, behavior trees, pathfinding, perception, dialogue and quests; do not fake remote AI services.
8. **Testing & Repair:** acceptance criteria, unit/integration/interaction/visual/performance/regression testing and bounded root-cause repair.
9. **Deployment & Git:** build, package, version control, GitHub workflows, deployment and handoff—with approval gates.

All modules must connect into a coherent user experience. Do not load unrelated dependencies or force 3D/complex physics into simple projects.
