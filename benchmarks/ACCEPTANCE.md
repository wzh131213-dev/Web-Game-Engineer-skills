# Cross-platform benchmark suite

Run independently on each platform and preserve evidence: (1) Web: add a feature to an existing site while preserving interactions. (2) 2D: movement, collision, pause/restart and touch. (3) 3D: procedural terrain/buildings, camera, lighting and collision. (4) Physics: gravity, rigid-body contact, boundaries and stability. (5) Legacy: modify only requested feature and regression-test untouched behavior. (6) Handoff: export project state and continue on another AI without AI-to-AI communication. (7) Delivery: source, resources, ZIP, tests, changelog and instructions.

Record host/product/version, adapter version, tools, steps, expected/actual, evidence, status and defects. Installation, security, schema migration and rollback are additional certification gates.
