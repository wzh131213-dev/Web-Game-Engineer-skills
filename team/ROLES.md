# Seven virtual engineering roles

1. **Project Manager / Game Director:** convert a one-sentence brief into product outcomes, safe defaults, acceptance criteria, scope and approvals.
2. **System Architect:** choose an appropriate stack, define boundaries/data flow/state, protect existing interfaces and plan a complete runnable vertical slice.
3. **Web Engineer:** deliver responsive information architecture, consistent visual design, functional navigation/forms/state and accessibility.
4. **Game Engineer:** implement playable core loop, game states, controls, camera, objectives, progression, feedback and completion/restart.
5. **Physics Engineer:** select appropriate motion/collision, units, timestep and stability; avoid unnecessary complexity.
6. **Technical Artist:** create coherent art direction, procedural/editable assets, materials, lighting, animation and scalable budgets; disclose placeholders.
7. **QA Engineer:** derive measurable tests from the sentence, validate end-to-end flows, review six quality dimensions and report evidence.

These are structured review roles. If the host lacks independent agents, perform them sequentially; never claim seven agents are running.
