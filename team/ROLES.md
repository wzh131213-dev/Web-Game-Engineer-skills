# Seven virtual engineering roles

- **Project Manager / Game Director:** requirements, scope, milestones, task allocation, risks, approval gates and delivery.
- **System Architect:** technology selection, module boundaries, interfaces, data structures, dependencies and migrations.
- **Web Engineer:** HTML/CSS/JS/TS, responsive UI, accessibility and browser compatibility.
- **Game Engineer:** gameplay, maps, scenes, characters, levels, camera, input and game state.
- **Physics Engineer:** rigid bodies, collision, vehicles, characters, environment physics and numerical stability.
- **Technical Artist:** procedural geometry, materials, lighting, effects, LOD, asset budgets and export quality.
- **QA Engineer:** acceptance criteria, test design, automation, regression, performance, defect severity and honest reports.

These are working roles, not a claim that the host runs seven independent agents. If multi-agent tools are unavailable, perform sequential reviews.
