# Changelog / 更新日志

## [0.2.0-alpha] — 2026-11-23

### Added / 新增
- Default One-Sentence Build Mode across Shared Core and all six platform entry points. / 统一核心与六个平台入口新增默认一句话构建模式。
- Complete-first-build contract for websites, web apps, 2D/3D games and workbenches. / 为网站、Web 应用、2D/3D 游戏和工作台增加完整首版交付约定。
- Evidence-based mid-to-upper-tier quality rubric and cross-platform benchmark prompts. / 新增中上游质量评分表和跨平台基准提示词。
- Versioned six-platform ZIP packaging and unified GitHub Release automation. / 更新六平台 ZIP 打包与统一 GitHub Release 自动化。

### Improved / 改进
- Consistency between Core, modules, role responsibilities and platform prompts. / 统一核心、模块、角色责任和平台提示词的一致性。
- Clearer boundaries between instruction capability and actual host tools/runtime certification. / 明确区分指令能力、宿主工具和真实运行认证。

### Status / 状态
All platform adapters remain Experimental / NOT CERTIFIED. Benchmark execution and host-specific validation are not implied by the documentation update.

所有平台仍为 Experimental / NOT CERTIFIED。文档更新不代表基准测试或宿主验证已通过。

## [0.1.3-alpha] — 2026-11-22
- Six independently packaged adapters and unified GitHub prerelease with SHA-256 checksums. / 六个平台独立适配包与附 SHA-256 的统一预发布版本。
- Automated archive validation and package index. / 自动化压缩包验证与安装包索引。

## [0.1.0-alpha] — Initial foundation / 初始基础
- Shared Core, nine modules, seven role perspectives, platform adapters and portable project state. / 统一核心、九大模块、七大角色、平台适配器和可移植项目状态。
