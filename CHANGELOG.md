## [0.1.3-alpha] — 2026-11-22

### Added / 新增
- Six independently packaged platform adapters: ChatGPT, Claude, Gemini, DeepSeek, Qwen and Doubao. / 六个平台独立适配包。
- Unified GitHub prerelease containing all six platform ZIP archives and SHA-256 sidecars. / 创建包含六个平台 ZIP 与 SHA-256 文件的统一 GitHub 预发布版本。
- Automated package validation and release workflow. / 自动化安装包校验与发布工作流。
- Platform-specific routes for Claude.ai/Claude Code, Qwen Code/Model Studio, DeepSeek chat/API and Doubao chat/Ark API. / 补充各平台不同宿主入口的独立适配路线。

### Improved / 改进
- Independent platform acceptance and certification records. / 平台独立验收与认证记录。
- Package index and distribution contract. / 安装包索引与分发规范。

### Status / 状态
All six platform adapters remain Experimental / NOT CERTIFIED. Host installation and runtime acceptance are not yet recorded as passed.

六个平台均仍为实验状态，尚无宿主安装与运行验收通过记录。
